# 2세대 설계 초안 (작업 중, 2026-10-01 시작) — 아직 동결 아님

사용자 결정(2026-10-01):
- 2세대 = 경기 국면 배분(A2 아이디어 발전): 호황에는 주식을 늘리고, 불황에는 국채·현금을 늘림.
- 국면 수는 **3국면·4국면 두 변형 모두** 계산.
- 호황 때 주식 부분 = **개별 종목 회전**.
- 추가 조사: 한 달 안에 위험을 빠르게 감지하는 방법(시장 급락, 뉴스 등).

1세대에서 배운 점(설계 요구사항):
1. 월별 실업률 신호는 1개월짜리 급락(2020 코로나)에 늦음 → 빠른 신호가 필요.
2. 물가발 하락장(2022)은 실업률 규칙에 안 보이고 국채도 함께 하락 → 물가 국면과 '국채 대신 현금'이 필요.
3. 단순 손절(E, 고점 −10%)은 휩소로 성과를 낮춤 → 빠른 신호는 확인 조건·부분 축소·명확한 복귀 규칙이 필요.
4. 개별 종목 선정(A0)은 같은 유니버스 동일가중을 못 이김 → 종목 선정은 동일가중 유니버스·SPY 대비로 검증.
5. 1998~2026 미국 자료는 전부 봤음 → 규칙은 문헌·논리로 먼저 정하고 동결, 검증은 다른 시장·전향 기간.

## 1. 구조 (3층)
| 층 | 주기 | 역할 |
|---|---|---|
| ① 국면(느린 신호) | 월 1회 | 확장·둔화·침체·과열 판정 → 주식/방어 자산 비중 |
| ② 빠른 위험 경보 | 매일 확인, 주 1회 복귀 판단 | 월중 급락·스트레스 감지 → 주식 부분 축소 |
| ③ 개별 종목 회전 | 월 1회(+경보 시 축소) | 주식 부분을 개별 종목 N개로, 국면에 따라 팩터 기울기 변경 |

## 2. 국면 정의 (초안)
성장 신호(월, 관측월 ≤ M−1): 실업률 > 12개월 평균, Sahm, **신규 실업수당 청구(ICSA, 주간)** 4주 평균의 추세 상승.
물가 신호(월): CPI(CPIAUCNS, 거의 수정 없음) 전년비 ≥ 3% 그리고 6개월 전보다 상승(초안).
주가 추세: 지수 < 10개월 평균(A2와 같음).

| 국면 | 3국면 변형 | 4국면 변형 |
|---|---|---|
| 확장 | 성장 신호 없음, 물가 정상 | 성장 신호 없음·주가 추세 위, 물가 정상 |
| 둔화 | — | 성장 신호 또는 주가 추세 중 하나만 나쁨 |
| 침체 | 성장 신호 그리고 주가 추세 나쁨(A2와 같은 정의) | 같음 |
| 과열(물가) | 물가 신호 켜짐(성장 나쁘면 침체 우선) | 같음 |

국면별 비중(초안, 결과 보기 전에 확정 필요):
| 국면 | 주식(개별 종목) | 방어 자산 |
|---|---|---|
| 확장 | 90~100% | 나머지 현금 |
| 둔화 | 60% | 40%(물가 정상: IEF·현금 반반) |
| 침체 | 20% | 80%(물가 정상: IEF 50·현금 30) |
| 과열 | 50% | 50%(현금 30·금 20, **국채 제외**) |
- 방어 자산은 물가에 따라 다르게: 물가가 낮으면 중기 국채, 높으면 현금(단기 국채)·금.
- 주의: 물가 신호는 2022년을 잡지만 2021년(+29% 해)부터 켜져 상승분 일부를 놓침 → 비용과 효과를 같이 보고.

### 3.2 2020년 코로나에 대입해 본 시점 (대략, 실제 값은 백테스트로 확인)
| 날짜 | 사건 | 고점 대비 |
|---|---|---|
| 2020-02-19 | S&P 500 고점 | 0% |
| 2월 말 | 200일 평균 하향 이탈, VIX 30~40, VIX 기간구조 역전 | 약 −10~−13% |
| 3월 중 | BAA 스프레드 확대 | |
| 2020-03-23 | 바닥 | −34% |
| 2020-03-26 | 실업수당 청구 330만 건 발표 | |
| 2020-04-03 | 3월 실업률 발표 → A2 신호는 4월 말에야 켜짐 | (이미 반등 중) |
- 시장 기반 신호(가격·변동성)는 고점 뒤 1~2주, 약 −10% 부근에서 켜짐. 바닥(−34%) 전에 일부를 피할 수 있지만 첫 −10%는 못 피함.
- 거시 신호 중 가장 빠른 것은 주간 실업수당 청구(바닥 직후). 실업률은 6주 뒤.

### 3.3 경보 규칙 설계 원칙(E의 실패 반영, 초안)
- **확인 조건:** 서로 다른 종류 2개 이상 동시(예: 가격 추세 + 변동성, 또는 가격 + 신용)일 때만 경보 → 단일 가격 신호의 휩소 줄임.
- **부분 축소:** 경보 시 주식 부분을 0이 아니라 절반 등으로 줄임(국면 비중 위에 곱함).
- **복귀:** 경보 신호가 모두 꺼지면 주 1회(주초) 복귀. '판 가격보다 위' 같은 가격 조건은 쓰지 않음(E에서 구조적으로 비싸게 되사는 원인).
- 뉴스 지수(EPU·감성)는 확인 조건의 보조 후보로만, LLM 뉴스 해석은 운영 단계의 사람 확인용(백테스트 성과에 넣지 않음).

## 4. 개별 종목 회전 (초안)
- 유니버스: 미국 대형주(시총 상위 ~500), 1세대 데이터 문제(재무 누락·생존편향)를 줄이기 위해 대형주 위주.
- 보유 수: $20,000 기준 20~30종목(1세대는 60종목이라 소액 주문·현금이 많았음). 소수점 주문 가능 여부는 브로커 결정과 연결.
- 회전 = 국면에 따라 점수 구성 변경:
  - 확장: 모멘텀 + 퀄리티
  - 둔화·과열: 퀄리티 + 저변동성(+가치)
  - 침체에서 막 벗어난 회복 초기: **모멘텀 비중 축소**(약세장 뒤 반등기에 모멘텀이 크게 무너지는 'momentum crash', Daniel–Moskowitz)
- 월중 교체 변형(선택): 경보·손절로 판 종목을 다음 순위 종목으로 교체할지 → E 결과로 보면 기본안은 '교체 없음', 변형으로만 비교.
- 비교 기준: 같은 유니버스 동일가중, SPY, 1세대 SPY B. 1세대처럼 무작위 대조군·DSR·PBO 포함.

## 5. 검증 계획 (초안)
| 단계 | 내용 |
|---|---|
| 사전 등록 | 국면 정의·비중·경보 규칙·종목 점수를 문헌·논리로 정하고 동결(결과 보기 전) |
| 미국 1998~2026 | 이미 본 자료 → 동작 확인과 1세대 대비 참고용(판정에 쓰지 않음) |
| 다른 시장 | 같은 규칙을 선진국(EFA)·일본(EWJ)·신흥국(EEM) 등 ETF 경로에 적용해 국면·경보 층이 재현되는지 |
| 민감도 | 사전에 정한 소수의 이웃 값(예: 200일 vs 150일, VIX 25 vs 30)만 보고, 선택에 쓰지 않음 |
| 전향 | 동결 후 모의투자로 실제 기간 평가(1세대 SPY B와 나란히) |
- 한도: 1세대와 같은 계좌 낙폭 30%(바꾸려면 Stage 0 새 결정).

## 6. 다음에 정할 것
1. 국면 정의(성장·물가 신호와 기준값)와 국면별 비중.
2. 빠른 경보에 쓸 신호 묶음과 규칙(몇 개 동시, 얼마나 줄일지, 복귀 조건).
3. 종목 회전: 유니버스 크기, 보유 수, 국면별 점수 구성, 월중 교체 여부.
4. 검증: 다른 시장 목록, 판정 기준(1세대 SPY B 대비 무엇을 넘어야 채택인지).
